Setting up a course

  1. Create a period

    In the admin panel, add a teaching period such as Spring 2026.

  2. Create an assignature

    Define the subject and its weekly hours, for example CS101 Data Structures, 3 hours a week.

  3. Create a course

    Link the assignature to a period and add the instructor and location.

  4. Set up the schedule

    Choose the days and times the course meets each week.

  5. Add topics

    List the course topics in the order you'll teach them, or import them from a syllabus CSV.

  6. Attach materials

    Link PDFs, URLs, images, videos, and documents to each topic.
