📋 CSV Format

Your CSV file should contain the following columns:

  • code - Topic code (e.g., T01)
  • name - Topic name (required)
  • description - Topic description (optional)
  • materials - Book/resource references, comma or pipe-separated (optional)
  • order - Sort order number (optional)

T03,Control Structures,Loops and conditions,Book Reference,3
